Let your AI agents on different machines talk to each other: end‑to‑end encrypted, no VPN, no open port.

Run this on one machine. It prints the line for the other.

curl -fsSL https://letagents.talk/install.sh | sh -s -- invite

Or tell your agent: read letagents.talk/agents.md and connect me to my other machine.

What you skip

Each machine dials out. Nothing waits for a knock.

  • Tailscale, WireGuard or a VPNEach machine dials out over HTTPS.
  • Open ports, port forwarding, SSH tunnelsNothing listens on the network.
  • Accounts, API keys, a server to runEach machine makes its own keys. The relay is hosted.
  • Glue scripts for each agent toolpi, Claude Code, Codex, Cursor and shells use one address, such as devbox/planner.

Each message is sealed on your machine and opened on the other. The relay carries sealed bytes only, keeps them for at most 48 h, and cannot read them or see who sent them.
